# Датасет карточек Ozon «Кофе в зёрнах»

Учебный проект: сбор структурированных данных о кофе в зёрнах с Ozon для анализа и ML.

## Что сделано

Собран датасет карточек товаров категории «Кофе в зёрнах». Данные извлечены со страниц Ozon и включают как базовые сведения о товаре (название, бренд, цена, рейтинг, отзывы, описание, продавец), так и характеристики (обжарка, состав, содержание арабики, страна происхождения, срок годности, условия хранения и др.).

Исходная выборка — 5317 карточек. После очистки — 5059 карточек кофе в зёрнах (удалено 258: снятые с продажи, молотый / растворимый кофе, капсулы, дрип-пакеты, кофе «3 в 1», сопутствующие товары из рекомендаций Ozon и карточки с валютой не RUB).

Дополнительно исправлены системные ошибки Ozon, из-за которых вес упаковки и цена за кг были искажены (units-баг, брутто-вес, мультипаки).

## Этапы работы

1. **`collect_catalog.py`** — сбор ссылок на карточки из категории.
2. **`parse_cards.py`** — извлечение данных с каждой карточки.
3. **`clean_dataset.py`** — очистка датасета: фильтрация, нормализация брендов, исправление веса и количества в упаковке, расчёт цены за кг.
4. **`diagnose_dataset.py`** — финальная диагностика очищенного датасета (24 проверки, все проходят).
5. **`describe_dataset.py`** — описательная статистика по всем колонкам.

## Ограничения

- Используются только публичные данные карточек. Ограничения доступа Ozon не обходятся.
- На Ozon отсутствует поле «количество оценок» — соответствующая колонка всегда пустая.
- Данные актуальны на момент сбора; часть карточек со временем снимается с продажи.
- **2 карточки** помечены `is_outlier_price=True`: Panama Geisha (153 100 ₽/кг) и Kopi Luwak (112 360 ₽/кг) — реальные элитные сорта, а не ошибка данных.
- **133 группы дубликатов** по `(name, brand, weight_g_actual)` — один товар у разных продавцов. Для ML-моделей (этап 3) нужен grouped split во избежание leakage.
