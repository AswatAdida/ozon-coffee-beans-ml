# Датасет карточек Ozon «Кофе в зёрнах»

Учебный проект: сбор структурированных данных о кофе в зёрнах с Ozon для анализа и ML.

## Что сделано

Собран датасет карточек товаров категории «Кофе в зёрнах». Данные извлечены со страниц Ozon и включают как базовые сведения о товаре (название, бренд, цена, рейтинг, отзывы, описание, продавец), так и характеристики (обжарка, состав, содержание арабики, страна происхождения, срок годности, условия хранения и др.).

Исходная выборка — 5317 карточек. После очистки — 5043 карточки кофе в зёрнах (исключены снятые с продажи товары, молотый кофе и сопутствующие товары из рекомендаций Ozon).

## Этапы работы

1. **`collect_catalog.py`** — сбор ссылок на карточки из категории.
2. **`parse_cards.py`** — извлечение данных с каждой карточки.
3. **`clean_dataset.py`** — очистка датасета (удаление нерелевантных карточек, нормализация брендов, расчёт цены за килограмм).

- 23 — распарсены частично (`ok_partial`)

**`coffee_beans_clean.csv`** — 5043 строки после очистки.

## Ограничения

- Используются только публичные данные карточек. Ограничения доступа Ozon не обходятся.
- На Ozon отсутствует поле «количество оценок» — соответствующая колонка всегда пустая.
- Данные актуальны на момент сбора; часть карточек со временем снимается с продажи.
